# Мой Будильник (Python Alarm Clock)

Простой консольный будильник на Python.

## Возможности
* Ввод времени в формате ЧЧ:ММ.
* Несколько будильников одновременно.
* Выбор: звук или текст.
* Настройка дней недели.
* Функция повтора.
